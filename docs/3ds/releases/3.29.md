## What’s new

- Fixed missing town scenery and NPC sprite coverage at the right edge of the upper screen by rendering one additional off-screen tile column before clipping. Dungeon tile coverage is unchanged.
- Clear the native world buffer before drawing a new scene, so transparent town tiles cannot retain pixels from the previous camera position. Repeated frames keep the last complete scene.
- Corrected the installation instructions: use **`/3ds/devil3ds/`** for `devil-3ds.3dsx` and your game data, rather than `/3ds/devil-3ds/`.
- Existing `/3ds/devilutionx/` installations remain supported when `/3ds/devil3ds/` does not exist. Keep your saves and settings when updating.

## Downloads

- **`devil-3ds.cia`** — install from the HOME Menu using a CIA installer.
- **`devil-3ds.3dsx`** — Homebrew Launcher; place in `/3ds/devil3ds/`.
- **`SHA256SUMS`** — checksums for both packages.

Copy your own **`DIABDAT.MPQ`** into **`/3ds/devil3ds/`**. Hellfire also requires `hellfire.mpq`, `hfmonk.mpq`, `hfmusic.mpq` and `hfvoice.mpq`. Original game data is not included.
