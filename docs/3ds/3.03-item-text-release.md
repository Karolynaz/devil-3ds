# Devil-3Ds 3.03

## Changes

- Ground item labels use the same top-screen glyph metrics as rendering. Long names wrap, stay within the screen and use bounded collision placement. The selected item takes priority in crowded piles.
- Identified unique item powers appear in the lower-screen info panel, including when floating tooltips are enabled. Long descriptions wrap and scroll. Invalid unique IDs are ignored safely.
- Multiline alignment no longer converts character spacing twice. Floating tooltips use native inventory, stash and belt coordinates and stay within their screen. Help and credits use the correct width and height limits.
- Existing native bitmap fonts and pixel rendering are retained. World zoom and the working multiplayer/update implementations are unchanged.

## Verification

All 23 host regression scripts passed with their required inputs, including EN/LT menu and settings measurements, multiline alignment, pixel geometry, framebuffer formats, small map, keyboard, TLS, data errors and Hellfire assets.

The new item test exercises 225 ground-name cases with shipped glyph widths, edge positions, a crowded 100-item pile, all six unique powers with floating tooltips on/off, power termination and invalid unique IDs under ASan/UBSan. The ZeroTier binding failure-injection test uses the pinned dependency checkout.

The GitHub 3DS workflow cross-compiles CIA and 3DSX packages, checks bundled assets and verifies the actual ELF, CIA and 3DSX stack allocations. Downloaded artifact hashes and version markers are checked before release.

No emulator or console is run by Codex. Multiplayer was reported working by the user on the preceding build. Hellfire gameplay still needs device testing.
