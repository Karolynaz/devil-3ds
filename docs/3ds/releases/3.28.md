## What’s new

### Console controls and spells

- All four spell and skill shortcuts — **(X), (Y), (L), (R)** — cast once per press.
- Offensive spells automatically target a nearby visible enemy with a clear path. Teleport, Golem, walls and runes use the direction your hero faces.
- Heal Other and Resurrect resolve an eligible nearby ally independently of the primary spell, including when the casting animation finishes.
- In **Spells & Skills**, press **(A)** on a spell to open its binding screen. Assign with **(X), (Y), (L), (R)**, or select a slot and press **(A)**.
- Updated console help and special-action confirmation/cancellation with **(A)/(B)**.

### Inventory, belt and shops

- Tap a bottom-screen spell icon to cast it. Hold a belt potion or scroll to use it; drag between belt slots to move or swap items.
- Fixed visual shop selection and added vendor page navigation with **(L)/(R)**.
- In the visual shop, **(Y)** requests a sale and shows its price; **(A)** confirms and **(B)** cancels.
- Fixed sale gold accounting and inventory-capacity checks. Failed purchases now explain whether gold or inventory space is missing.

### Heroes and Hellfire

- On **New Hero**, press **(A)** to create a Hellfire hero when the expansion files are installed, or **(Y)** to create an original Diablo hero.
- Fixed the new Hellfire hero intro being skipped by the held creation button.

### Separate installation and existing saves

- Devil-3Ds now has its own CIA identity and installs as a separate HOME Menu title alongside the original DevilutionX.
- New installations use **`/3ds/devil3ds/`** for game data, settings and saves. Copy your own **`DIABDAT.MPQ`** there; for Hellfire, also copy **`hellfire.mpq`, `hfmonk.mpq`, `hfmusic.mpq`, `hfvoice.mpq`**.
- If `/3ds/devil3ds/` does not exist but `/3ds/devilutionx/` does, the game uses the existing folder automatically. Keep that folder to continue using existing saves without migration. If both folders exist, `/3ds/devil3ds/` takes priority.

### Sleep/wake stability

- Added recovery of input, pointer timing and graphics presentation after closing/reopening the console or returning from HOME.
- Waking cancels unfinished touch, hold and vendor-button actions instead of accidentally using, dropping or selling an item.
- These changes address identified resume-state problems. The reported intermittent hardware freeze still needs confirmation on a physical 3DS; it is not claimed fully resolved.

## Downloads

- **`devil-3ds.cia`** — install with a CIA installer.
- **`devil-3ds.3dsx`** — launch with the Homebrew Launcher.
- **`SHA256SUMS`** — checksums for both packages.

CIA installer version: **3.28.0**. Original game data is not included.

Validation: nine targeted host regression suites and the full 3DS build, including package assets, CIA identity/version and stack checks. No emulator or physical-console testing was performed for this release.
